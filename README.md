# Goonpilot

A personal booru viewer that runs on your own computer. No accounts, no cloud, no dependencies (just Node.js 18+). Everything you like, save or change stays on your machine.

**Quick start:** on Windows, double-click `launchers\start.bat`. On macOS or Linux, run `node server.mjs`. Then open http://localhost:8787.

Setup, phone access, image analysis, favorites and troubleshooting are covered in the **[wiki](https://github.com/swagamaniac/goonpilot/wiki)**.
